# CC Pro — Caption Editor

A Jetpack Compose Android caption editor starter with video import and ExoPlayer preview.

## Features

- Video import from device storage
- ExoPlayer video preview
- Multiple caption clips
- Live caption text editing
- Caption selection timeline
- Dark, CapCut-inspired interface

## Build

1. Open this repository in Android Studio Iguana or newer.
2. Let Gradle download dependencies.
3. Connect an Android 8.0+ device.
4. Run the `app` configuration.

## Stack

- Kotlin
- Jetpack Compose
- AndroidX Media3
- MobileFFmpeg
